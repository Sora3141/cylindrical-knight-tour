# Cylindrical Knight's Tour — 円筒ナイトツアー

**円筒（左右の端がつながった盤）**でのナイトツアー パズルです。
端を越えると反対側へループするため、平面とは違う経路が生まれます。
Three.js による 3D 表示で、円筒を回しながらプレイできます。

## 🔗 リンク

- リポジトリ: https://github.com/Sora3141/cylindrical-knight-tour
- デモ: https://sora3141.github.io/cylindrical-knight-tour/

## 概要

- 円筒面上のナイトツアー。左右がつながっているため端からの折り返しが可能。
- 移動可能なマスをハイライトし、クリック / タップで進む。
- **UNDO**（1 手戻る）・**REBOOT**（やり直し）対応。
- ドラッグで視点回転・ホイール / ピンチでズーム。

## 使用技術

- **Three.js**（3D 描画）
- HTML / CSS / Vanilla JavaScript
